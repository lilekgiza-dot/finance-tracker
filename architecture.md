# finance-tracker — архитектура

Личный трекер доходов/расходов Лилии (Telegram Mini App, стиль "Касса"). Не для клиентов — только для себя.

## Стек

Никакого бэкенда и сборки. Два файла:
- `index.html` — вся вёрстка + стили + вся логика на чистом JS (без фреймворков/библиотек), рендер строится из строк через `render(data)` и вложенные `renderX(data)` функции, вставляется в DOM через `innerHTML`.
- `data.json` — вся база данных проекта. Читается через `fetch("data.json?v=" + Date.now())` при загрузке страницы (кэш-бастинг через `?v=`, чтобы GitHub Pages / Telegram WebView не отдавали старую версию).

Хостинг — GitHub Pages (репозиторий `lilekgiza-dot/finance-tracker`, ветка `main`, `https://lilekgiza-dot.github.io/finance-tracker/`). Кнопка меню в Telegram-боте называется "Финансы" и открывает эту страницу как Mini App.

## Как вносятся данные

Данные НЕ вводятся через саму страницу — она read-only витрина. Лилия присылает агенту (боту) фото чека или текстом сумму/категорию, агент сам редактирует `data.json` (через `git clone` в свой scratchpad → правка JSON → `git commit` + `git push`) и ждёт, пока GitHub Pages пересоберётся (проверяется через `gh api repos/.../pages/builds/latest`).

## Структура data.json

```
{
  updated_at, month_label, month_start, days_in_month,
  balance_label, balance,
  accounts: [{name, amount}],              // Т-банк / Халва / Наличные — реальные остатки из банка
  bills: [{name, amount, paid, actual, is_bill}],
     // amount = план, actual = факт за месяц
     // is_bill=true — только настоящие закрывающиеся платежи (квартплаты), для них paid даёт зелёную галочку
     // is_bill=false — открытые бюджетные категории (Еда, Хозтовары...), галочки нет, показывается как факт/план
  annual_report: { ... },                  // архив прошлых месяцев (например archive.июль)
  categories: {
    income:   [{name, plan}],
    mandatory:[{name, plan}],               // обязательные траты
    optional: [{name, plan}],               // необязательные
    savings:  [{name, plan}]
  },
  operations: [{date, group, category, type, amount, note, account}]
     // group = mandatory/optional/income/savings — привязка к categories
}
```

## Вкладки (нижняя навигация, `window.switchView`)

- **Главная** — `renderHero` (баланс-герой, 4 KPI-карточки), `renderPeriodBar`, `renderCategoryList` (донат по категориям с раскрытием операций)
- **Операции** — `renderOps`, лента всех операций, сортировка по дате
- **Оплаты** — `renderBillsView`, План/Факт/Отклонение по `bills[]`, значок ✅/🔲/📊 зависит от `is_bill`+`paid`
- **Заметки** — заглушка, не реализовано
- **Настройки** — `renderAccounts`, остатки по счетам + `renderAnnual`, компактный годовой отчёт

Иконки категорий — фиксированная карта `CAT_ICONS` в начале скрипта; при добавлении новой категории в `data.categories` нужно добавить и иконку туда же, иначе будет пусто.

## Известные пробелы (сознательно не реализовано)

- День/Неделя/Год в период-баре не пересчитывают данные — работает только Месяц
- Заметки — пустая вкладка
- Голосовые сообщения не поддерживаются агентом (нет транскрипции), только фото/текст

## Правила при изменениях

- Любую правку JS проверять `node --check` на извлечённом `<script>`-блоке перед пушем
- После пуша дожидаться `status: "built"` через Pages API, не полагаться на "не вижу изменений" = сразу кэш — иногда это реальная ошибка сборки
- Не переусложнять: это личный инструмент на двух файлах, не продукт — новые абстракции/библиотеки не добавлять
